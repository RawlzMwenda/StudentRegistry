# Student Registry Console Application

Maven-managed Java 21 console application demonstrating OOP, inheritance, exceptions,
a generic repository, collections, and streams.

## Run
```bash
mvn clean compile
java -cp target/classes com.studentregistry.Main
```

## Features
- Add undergraduate/postgraduate students
- List students and search by ID
- Validate blank names and GPA range (0.0–4.0)
- Generic in-memory repository and Java streams
